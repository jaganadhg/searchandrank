# Files generated (Claude) — LITE re-ranker reproduction

All files created/modified on branch `feat/paper-faithful` for the faithful LITE
(Learnable Late Interaction) document-ranking reproduction. Grouped by purpose.

## Source package — `src/literank/`

| File | Purpose |
|---|---|
| `__init__.py` | Package marker / version. |
| `config.py` | `ModelConfig`, `TrainConfig`, `DataConfig` dataclasses holding all paper + run hyperparameters (defaults). |
| `encoder.py` | `DualEncoder` — shared HF encoder → token embeddings, with padding-mask zeroing, L2-norm, and optional projection (Small-LITE lever). |
| `model.py` | `LITEScorer` (separable row/column MLP late-interaction scorer), `MaxSimScorer` (ColBERT-style baseline), `build_scorer`, and `Ranker` (encoder + scorer). |
| `losses.py` | Margin-MSE + KL distillation losses (`distill_loss`). |
| `teacher.py` | `CrossEncoderTeacher` wrapper + teacher-score caching (atomic write). |
| `data.py` | `TripletDataset`, `collate_triplets`, MS MARCO triplet builder, and `build_eval_set` (per-query eval examples). |
| `checkpoint.py` | `save_checkpoint` / `load_checkpoint` (resume) + `prune_checkpoints` (keep newest N, avoids filling disk). |
| `train.py` | Distillation training loop: AMP, gradient accumulation, checkpoint/resume, progress logging, periodic dev-MRR eval + early stopping. |
| `encode_cache.py` | Offline encode + cache of document token embeddings (demonstrates the storage lever). |
| `rerank.py` | Rerank candidate docs against a query using cached embeddings. |
| `evaluate.py` | `mrr_at_k`, `ndcg_at_k`, and `evaluate_ranker_mrr` (dev MRR via `model.score`). |
| `cli.py` | `python -m literank.cli` entry point: `train`/`encode`/`rerank`/`eval` subcommands + all training flags; sets up logging. |
